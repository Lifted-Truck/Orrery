# Screenshot capture list

Drop PNGs here with these exact names and the README picks them up.
Standalone at its default 980×720 is the intended source; a plain window capture
(no desktop background) reads best on GitHub in both light and dark themes.

| File | What it should show |
|---|---|
| `orrery-elastic.png` | The **Elastic** tab, transport RUNNING. Ideally mid-relaxation: particles slightly off the cyan E(k,n) ghost diamonds with a couple of energy whiskers showing, so the "settles toward Euclid" idea is legible. The `Δ … settled ✓` readout is a nice detail to have visible. |
| `orrery-measured.png` | The **Measured** tab with a non-flat curve — a hump or ramp — so the deformation links between the cyan flat-measure ghosts and the amber onsets are clearly fanned out. Any draw mode. |
| `orrery-probable.png` | The **Probable** tab with `temperature` up around 0.4–0.6, so there's a visible spread of radial probability bars and a mix of realized/unrealized steps. |
| `orrery-offset-lane.png` | A close crop of the **offset lane** with 2–3 cells pinned (amber, lock dot) and `walk`/`accent` chips on — the pins-and-flow rule in one image. Cropping to just the lane is fine and probably clearer than a full window. |

Optional extras, if you want them the README can grow a section:
`orrery-ableton-routing.png` (a Live track with **MIDI From → Orrery**) and
`orrery-standalone.png` (the whole window, for a hero shot).
